# 01 项目启动说明

## 1. 项目名称
校园活动报名与签到管理系统

## 2. 项目目标
- 支持活动发布
- 支持学生报名
- 支持名单审核与二维码签到
- 支持签到统计与活动总结导出

（注：本次实验聚焦项目管理文档与版本协作，不实现完整业务系统，但以上述目标为背景展开范围计划。）

## 4. 项目边界

### 纳入范围（本次实验交付物）
1. 版本管理基础设施  
   - GitHub 仓库创建与成员邀请  
   - 本地目录结构（docs/, src/, test/, assets/）  
   - 首次初始化提交
2. 项目管理文档  
   - 项目启动说明（本文件）  
   - 三级 WBS 分解文档（`02-wbs.md`）  
   - 简化进度计划（`03-schedule.md`）  
   - 配置管理方案（`04-config-plan.md`）
3. 协作实践成果  
   - 冲突制造与解决（`conflict.md` + `conflict-resolution-log.md`）  
   - 分支合并记录（main 分支包含所有最终文档）
4. 总结报告  
   - `05-summary-report.md`，由全体成员共同完成并提交至 main 分支

### 不纳入范围（本次实验不做）
- 实际业务系统的代码开发（如签到二维码生成、数据库设计等）
- 系统部署与运行
- 用户界面设计
- 测试用例编写与执行
