# 校园活动报名与签到管理系统

学校拟开发一套活动发布、报名、签到、统计等功能的系统。本实验聚焦项目管理文档与版本协作。

## 目录结构说明
- `README.md` - 项目说明与协作约定
- `docs/` - 项目管理文档
  - `02-wbs.md` - 三级 WBS 分解
  - `03-schedule.md` - 简化进度计划
  - `03-config-management.md` - 配置管理方案
  - `conflict.md` - 冲突示例及解决结果
  - `05-summary-report.md` - 实验总结报告
- `src/` - 源代码（本次实验未使用）
- `test/` - 测试代码
- `assets/` - 图片等资源

## 分支策略
- `main` – 受保护的主分支，仅通过合并 PR 更新
- `dev` – 集成测试分支（本实验未单独使用）
- `feature/*` – 功能开发分支
- `hotfix/*` – 紧急修复分支

## 协作约定
- 提交信息格式：`<type>: <subject>`，如 `docs: 添加配置管理方案`
- 合并前需在分支上完成自测，合并由配置管理员执行
- 冲突解决后必须由另一名成员复核，确认无误后合并
